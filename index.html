About

How I work

I care most about the part of a program you can't see: how the server keeps players in sync, where data gets checked, how the pieces talk to each other.

Most of what I know I learned by building something, watching it break and working out why. My first Roblox game taught me debugging and system design before I knew those words. Since then I've built a website for a real client, full-stack apps with databases and authentication, and a multiplayer game system.

At university I want to get the foundations right: algorithms, data structures, computer systems, maths and AI. I'd like to do that in China, where so much technology is built and used at a scale I haven't seen anywhere else.
